One sentence that convinces a friend who has never coded to let an AI agent build their first app idea on make.fun. Built for the [A Day of One-Line Pitches](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3) competition on make.fun.

## The line

> Tell an AI agent on make.fun the app idea you've been carrying around in your head, in your own words, and it'll build it into a real app you can tap — free, no code, and you can walk away if you don't love it.

210 characters, one sentence. It speaks to a friend with an idea they've been carrying around, in their own words, with a real app they can tap as the payoff — free, no code, and no commitment if they don't love it.

## Run it

```sh
node main.ts
```

Node 22 or later. No dependencies, no network. The program writes the line to `/output/entry.txt` (created if needed), mode 0644.
